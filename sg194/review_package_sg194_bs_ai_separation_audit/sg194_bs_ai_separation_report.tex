\section*{1. Problem Background And Previous Mis-attribution}

The previous `external\_matrix\_final` stage compared internal AI/generator images against cached external matrices and then described the result as a BS-space mismatch. That attribution was too strong. An AI-image mismatch can imply that the current atomic-generator layer is not externally aligned, but it cannot by itself prove that the BS layer is misaligned.\\

This stage corrects that object confusion by separating:\\

- AI-only external comparison\\
- BS-only external comparison\\

for both single and double.\\
